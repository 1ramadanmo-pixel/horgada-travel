# Hurghada Life Tours

موقع تعريفي ثابت لرحلات الغردقة والبحر الأحمر، مبني بصفحات HTML وCSS وJavaScript، من دون خطوات بناء أو تثبيت حزم.

## الصفحات

- `index.html` — الصفحة الرئيسية.
- `overview.html` — نبذة والأنشطة.
- `project-three.html` — الرحلات والخدمات.
- `about us.html` — أقسام السفاري والجزر والرحلات البحرية.
- `gallery.html` — معرض الصور مع البحث والتصفية والعرض المكبر.
- `contact.html` — معلومات التواصل.

## التشغيل محليًا

افتح `index.html` مباشرة، أو شغّل خادم ملفات بسيط من مجلد المشروع:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح.

## الصور

- صور الصفحات الرئيسية موجودة في `assets/images/modern/`.
- صور المعرض الفريدة والمضغوطة موجودة في `assets/images/gallery/photos/`.
- المعرض يحتوي 153 صورة فريدة بعد إزالة الصور المتطابقة. الصور مصغرة إلى حد أقصى 720 بكسل لتقليل حجم الرفع مع الإبقاء على نسخة مناسبة للعرض المكبر.
- لا تضف ملفات `.DS_Store` أو صورًا مكررة إلى المشروع؛ يتجاهلها `.gitignore`.

## النشر على GitHub Pages

من إعدادات المستودع اختر **Settings → Pages → Deploy from a branch**، ثم حدّد الفرع ومجلد الجذر `/`.

تتضمن الصفحات عناوين وأوصافًا مستقلة، وتحتوي صفحة التواصل على بيانات النشاط المنظّمة المطابقة للمعلومات الظاهرة فيها. يلزم إضافة النطاق المنشور إلى وسوم `canonical` و`og:url` وإنشاء `sitemap.xml` قبل الإطلاق؛ لا تستخدم `eu-cod.eu` لهذه الوسوم لأنه رابط اعتماد التصميم.

## الصيانة

- روابط حجز الرحلات عبر WhatsApp تستخدم الرقم الموجود في روابط `wa.me` داخل صفحات الرحلات و`assets/js/gallery.js`.
- تنسيقات الإضافات الحديثة في `assets/css/modern.css`، وتفاعلات الموقع في `assets/js/modern.js` و`assets/js/gallery.js`.
